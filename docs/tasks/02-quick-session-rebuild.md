# Aufgabe: Kurzrunde

Die Kurzrunde ist eine gemischte Übung mit zehn Aufgaben. Sie darf Lernkarten,
Quizfragen und Hand-Erkennung enthalten. Drück-Szenarien bleiben außen vor,
solange die Kurzrunde keine vollständige Auswahl von zwei Karten unterstützt.
Fehler werden bevorzugt, gesperrte Skat+-Inhalte herausgefiltert und reine
Erklärungskarten nicht als Scheinfragen behandelt.
